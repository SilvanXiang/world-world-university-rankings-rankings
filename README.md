# World World University Rankings Rankings

[Read the 2027 edition](https://silvanxiang.github.io/world-world-university-rankings-rankings/2027/) · [中文版](https://silvanxiang.github.io/world-world-university-rankings-rankings/2027/?lang=zh) · [About the project](https://silvanxiang.github.io/world-world-university-rankings-rankings/about.html)

The inaugural edition considers 75 real university rankings and awards 50 editorial places. Each placed ranking receives a bilingual citation. The candidate register includes the publisher, the edition consulted and links to primary sources.

The project home opens the current issue. The 2027 edition has a permanent directory and links to individual entries, including [the committee’s decision on QS](https://silvanxiang.github.io/world-world-university-rankings-rankings/2027/?lang=zh#ranking-qs).

## Files

The candidate register and editorial decisions are in [2027/edition.js](2027/edition.js). The original double-podium [icon](assets/mark.svg) and [illustration](assets/double-podium.svg) are SVGs. Font licences are included alongside the fonts in [assets/fonts](assets/fonts/).

GitHub Pages serves the repository root on `main`. A local preview can be served with `python -m http.server` from this directory.
